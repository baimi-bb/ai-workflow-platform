## 本次追加

### 1. 新增 workflow_run / task_run 运行态模型
- 新增 `workflow_runs`，用于表示某个 project 的一次完整 workflow 执行
- 新增 `task_runs`，用于表示某次 workflow 执行中的单个节点实例
- 将运行态与现有 `tasks` 模板节点正式分层：
  - `tasks` 负责流程定义
  - `workflow_runs` / `task_runs` 负责流程执行

### 5. 初始化 task_run 生成规则
- 创建 workflow run 时：
  - `start` 节点自动生成 `completed` 的 task run
  - 无依赖的普通 `task` 节点初始化为 `ready`

  - `end` 节点当前初始化为 `pending`
- `task_run` 会保存节点快照信息：
  - `title_snapshot`
  - `node_type`
  - `task_dependencies_snapshot`

### 6. 新增运行态 API 接口
