### 6. 后端新增 project planning 接口与 service
- 新增接口：
  - `POST /workspaces/{workspace_id}/projects/{project_id}/plan`
- 新增 `project_planning_service.py`
- 规划时会：
  - 校验 planner agent 必须属于当前 workspace 且处于可用状态
  - 读取当前 project 信息、现有 tasks、可用 agents
  - 调用所选 planner agent 生成结构化 JSON 规划结果

### 7. AI 规划结果会自动创建 tasks 与依赖
- 当前约定 planner 返回：
  - `summary`
  - `tasks`
  - 每个 task 可包含：
    - `title`
    - `description`
    - `priority`
    - `assigned_agent_id` 或 `assigned_agent_name`
    - `depends_on_titles`
- 服务端会先批量创建 task，再按标题映射补上依赖关系
- 当前实现为“追加生成”，不会自动删除或覆盖 project 里已有 task

### 8. 前端新增 project planning action / types / feedback
- 前端新增：

### 22. AI 生成后的节点初始布局优化为可读流程图
- AI 自动生成 workflow 后，不再只是把节点“连上”
- 现在会在落库后自动按依赖层级做初始排版：
  - `start` 固定在最左侧
  - 任务节点按依赖深度从左到右分层
  - 同一层的任务节点按上下顺序展开
  - `end` 自动放到最右侧

### 23. 布局规则与边界节点规则联动
- 在补齐默认依赖后，再执行自动布局
- 因此当前 AI 生成的 workflow 会同时满足：
  - 无前置依赖任务自动挂到 `start`
  - 无后置依赖任务自动汇到 `end`
  - 节点位置默认更接近一张可读的流程图，而不是散乱堆叠

### 24. 测试补充
